## MLR R² Score — Authoritative Value

The authoritative MLR R² for this project is **0.4644**, computed via
`sklearn.metrics.r2_score` on the 27 training parts. This value is stored in
`models/metrics.json` and is generated by `save_models.py`.

Some earlier project reports and slides cite a 91.94% or 90.56% figure — these
refer to a different custom accuracy metric (`mean(1 - abs_error / true_value)`)
computed alongside a feature combination selected for that metric, not R². That
figure measures mean relative closeness, not variance explained, and is not
comparable to R².

The **0.4644** figure is the correct one to use when asked about model
performance or R² for the MLR model. The CNN model's R² is 0.8953 and the
Fuzzy Logic model's R² is 0.1755, both computed by the same method.
