The fuzzy logic stage uses 81 rules because it has 4 inputs (Channel2 RMS, Channel3 Peak, Channel1 Crest Factor, Channel3 Spectral Entropy), each partitioned into 3 membership levels (Low, Medium, High). A complete, exhaustive rule base requires one rule per combination of levels across all inputs: 3^4 = 81. This ensures every possible input combination has a matching rule, avoiding gaps in the fuzzy inference system.
